## Policy
- Validation was used only for post-fit evaluation.
- Chronological cross-validation used TRAIN only with fold-local scaling.
- The final TEST partition was not evaluated or used for model selection.
- No feature selection, class rebalancing, or hyperparameter optimization was performed.

## Assessment
- Weak evidence of class discrimination beyond the majority baseline on balanced accuracy and macro F1, but poor temporal generalization, lower overall validation accuracy, and near-absent BUY recall prevent calling the current baseline robustly learnable.
- Next stage: Diagnose temporal drift and session/price-level dependence using TRAIN and VALIDATION only before any controlled feature or hyperparameter experiment; keep TEST sealed.
