# ML-Trading-System
An Intelligent Trading Decisions Engine

## Project Structure

```
ml-trading-system/
├── data/           # Raw and processed market data
├── notebooks/      # Jupyter notebooks for exploration and analysis
├── features/       # Feature engineering scripts and pipelines
├── models/         # Trained model artifacts and definitions
├── training/       # Model training scripts and configuration
├── backtesting/    # Backtesting framework and results
├── live/           # Live trading execution logic
├── mql5/           # MQL5 scripts for MetaTrader integration
├── tests/          # Unit and integration tests
├── config/         # Configuration files
└── README.md
```
